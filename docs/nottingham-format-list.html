Nottingham Format List: who fills what

Hull has a file with one row per product on each line. Nottingham has none, so Brand, Unit Size, Unit Count/Format and Extra Info stay empty on every Nottingham row. This page shows the file, and which columns we can fill from Provideam data and which need Nottingham.

1. The Hull file (the model)

One row per line and product name. The product name at Hull carries the format, so the other columns read straight from it.

3. How many cells each group covers

Rough pattern match on 331 Nottingham plan rows on the packing lines (Maintenance excluded). Not checked by eye.

Known now

Site, Machine, Product Name

  • 100% from the Provideam plan rows
  • Unique Machine Name and Product Key built by the flow
Rule

Unit Size, Unit Count/Format, Extra Info

  • Unit Size: about 80% have a pack count or strength in the name
  • Unit Count/Format: about 50% have a blister or strip count
  • Extra Info: words like Standard outer, Tray, XL leaflet, Booklet, country code
Nottingham

Brand, and every gap

  • Brand: only about 33% have a brand word in the name
  • Material codes (0108286, HLTK0, 3003502) need a code to brand list: about 25 codes, not 512 products
  • Names that are only a code (3225330) need the full row
